# Ambience audio

Real tracks that ship with the app, looped by the Prayer Timer's ambience
pills (`lib/features/timer/ambience_player.dart`):

- `meditation.mp3`
- `silence.mp3`
- `tenderclouds.mp3`

To swap or add a track, drop the file here and update the `_fileFor` map
in `ambience_player.dart` (and the pill list in `timer_screen.dart`) to
match.
